# Greek Delivery Platform

A production-minded, Greek-first delivery marketplace foundation for Athens-first launch.

## Product scope

- Customer mobile app (Expo / React Native)
- Courier mobile app (Expo / React Native)
- Merchant and operations workspace (Next.js)
- Shared domain package and Supabase/PostgreSQL backend
- Hybrid fulfilment: merchant fleet or platform courier fleet
- Initial pilot checkout: cash on delivery only; card payments are not enabled until a marketplace PSP is approved and verified

## Important status

This repository is a software foundation, not a live delivery business. No real merchants, couriers, customer data, payment credentials, delivery prices, or legal agreements are seeded. Production launch requires environment setup, migration review, PSP onboarding, legal/accounting review, operational tests, and app-store release work.
